# Loop 行为验证

这些是待执行的场景与判据，不是测试通过记录。

主持人逐个在仓库外的隔离工作区实现 `scenarios.json` 的 setup，使用当前 LOOP 模板，并保留实际文件和版本证据。给无继承上下文的被测 Agent 仅提供对应 prompt、工作区与 Skill 入口，不提供 checks、其他场景或预期结论。允许的修改范围和工具限制需在输入中明确。由独立审阅者按 checks 核对工具轨迹、文件差异和最终回答。

记录实际加载路径、源码差异/版本、模型、权限、输入和输出位置，逐项标记通过、失败、未执行或环境阻塞。直接加载 Skill 的演练不能证明安装后恢复或宿主工具可用；结构校验不能证明行为通过。恢复路径场景需要真实提供失效路径与可发现版本，不能只口头假设。

同时验证反例：有效验收应允许完成，可选润色不应无限重开。测试日志保留在仓库外，维护可复用场景而不把一次成功泛化为可靠性保证。
