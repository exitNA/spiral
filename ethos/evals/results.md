## 环境与入口

- 本机 macOS，Codex CLI 0.153.0；CLI 使用用户配置的模型，没有另行覆盖模型选择。
- 移除旧 `ethos@ethos`，安装并核对 `ethos@spiral`。最终源码和安装缓存均为 `0.1.0`，11 个发布文件的完整指纹一致：`ae497637679352d1cb3a45b3a7f13364ddbbbbd2e29296d13f3e389406b0b5ae`。
- 在 `/hooks` 中逐项审阅并信任两个 Ethos Hook。最初的明确纠正实验发生在信任前，只证明安装后技能的隐式调用；临时偏好和任务末尾证据实验发生在信任后。
- CLI 实验使用隔离临时 Git 仓库、`--ephemeral` 与 `workspace-write`。跨会话实验使用四个无历史继承的独立 Agent，只共享同一临时仓库，并直接提供 Skill 路径；它证明技能与磁盘证据链，不单独证明 Hook 触发。
- 临时运行原始输出未进入插件发布目录。结构测试、直接加载技能、已启用 Hook 的宿主运行分别判读。
